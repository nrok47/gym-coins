## กติกา coin (สรุป)

- ภารกิจรายวันกดได้วันละครั้ง, เวทเทรนนิ่งเป็นโควตา 3 ครั้ง/สัปดาห์
- "ชั่งวันนี้" ระบบให้เอง กดไม่ได้ — ได้เมื่อบันทึกผลชั่งของวันนี้
- "น้ำครบ 2.5 ลิตร" ระบบให้เอง กดไม่ได้ — ได้เมื่อยอดในชีต Water ของวันนี้ถึง 2,500 ml
- "ปิด window 18:00" กดเองได้ แต่ก่อน 18:00 (เวลาไทย) จะโดนปฏิเสธ
- streak เดินต่อเฉพาะเมื่อเมื่อวานทำภารกิจ ≥1 อย่าง เว้นวันเมื่อไหร่ = 0
- ได้จริงราว 4-9 coin/วัน → ~170/เดือน ราคาเบียร์ 150 = ประมาณเดือนละครั้ง

## v9 — 5 ต.ค. 69 (รอบ IF 18/6)

เหตุ: 4 ต.ค. 69 ชั่งใหม่ได้ BMI 26.0 / ไขมัน 24.6% / VF 12 / น้ำ 51.7% / กล้ามเนื้อ 53.77
→ น้ำหนัก **75.1 กก.** (ถอดจาก BMI x 1.70^2 ตรงกับ lean/(1-ไขมัน%))
เทียบ: baseline เดิม 73.9 (7 ส.ค.) · จุดต่ำสุดที่เคยทำได้ 70.8 (30 พ.ค.) · เครื่องคลินิก 72.24 (6 พ.ค.)

เพิ่ม:
- `CFG.BASELINE` 73.9 → **75.1** (progress bar จะไม่ติดลบ)
- `CFG.WATER_TARGET_ML = 2500` / `IF_CLOSE_HOUR = 18`
- ชีต **Water** + `addWater()` / `getWaterData()` / `waterToday_()` — สร้างเองแบบ lazy เหมือน Drinks
- แท็บ "น้ำ" ในเว็บแอป: หลอดความคืบหน้า + ปุ่มกด 4 ปุ่ม + กราฟ 7 วัน + รายการวันนี้
- ภารกิจ `m9` น้ำครบ (auto) และ `m8` ปิด window 18:00 (กดก่อนเวลาไม่ได้)
- เมนู "อัปเดต baseline ในชีต Dashboard" = `refreshBaselineInSheet()` เขียนแค่ B11

**ทำไมเป้าน้ำ 2.5 ล. ไม่ใช่ 3 ล.** — Gemini แนะ 3 ล. เพราะอ่านว่า "น้ำ 51.7% ต่ำกว่าเกณฑ์"

จึงเคลื่อนสวนทางกันเสมอ) ไขมันลง เลข % จะขึ้นเอง

## v10 — 5 ต.ค. 69 (เลิก hardcode เลขแถวใน Dashboard)

**ปัญหาเดิม:** `buildDashboard_` ฝัง `B3` / `B8` / `B11` / `B13` / `B21` / `B22` ไว้ในสูตร
แทรกแถวใหม่ 1 แถว = สูตรชี้ผิดช่องทั้งแผง **และพังแบบเงียบ** (ยังคำนวณได้ ไม่มี error ให้เห็น)
เป็นเหตุผลที่แถวน้ำค้างไม่ได้ใส่มาตั้งแต่ v9

**แก้เป็น key-based spec:**
- `dashSpec_(last)` คืน array ของ `{key, label, v, fmt, band}` — 1 รายการ = 1 แถว เริ่มแถว 3
- `v` ถ้าเป็นฟังก์ชันจะได้ `R('key')` มาใช้อ้างแถวอื่น เช่น `R => '=ROUND(' + R('ma') + '-70.8,2)'`
- `dashResolve_(spec)` แปลง key → เลขแถวจริง · `R()` ของ key ที่ไม่มี **throw** ไม่ใช่คืนค่าเงียบ · key ซ้ำ throw
- `{}` ว่างในสเปค = แถวคั่น (เดิมคือ `['','']`)
- format / สีแถบ อ่านจาก `fmt` / `band` ของแต่ละรายการ ไม่ใช่ `getRange('A18:B19')` แบบตายตัว
- `refreshBaselineInSheet` หาแถวจาก **ป้ายในคอลัมน์ A** (`dashRowByLabel_` + `DASH_LBL`) → ชีตเวอร์ชันเก่าก็ยังแก้ได้

**แถวน้ำที่เพิ่ม** (5 แถว แถบฟ้า): น้ำวันนี้ (ml) · เป้า · % ของเป้า (มี gradient) · เฉลี่ย 7 วัน · 7 วันนี้ถึงเป้ากี่วัน
helper ใหม่ **คอลัมน์ U/V** (U = วันที่ย้อนหลัง 7 วัน · V = ยอด ml ของวันนั้น) เพราะ SUMIFS รายวัน 7 วันเขียนในสูตรเดียวไม่ได้
\+ กราฟแท่งน้ำ 7 วันที่ตำแหน่ง (34, 4)

**`rebuildDashboardOnly()` — เมนูใหม่ที่ต้องใช้แทน `setupTracker`**
Dashboard สร้างใหม่ได้ฟรีเพราะไม่มีข้อมูลของตัวเอง มีแต่สูตรชี้ไปชีตอื่น
`setupTracker` ยังเป็นตัวที่ล้าง Log อยู่ **ห้ามแนะนำให้รันเพื่ออัปเดตแผง**

**`testDashboardSpec()` — เทสที่ควรมีตั้งแต่แรก** Run ใน editor ไม่แตะชีต
เช็ก 5 ข้อ: (1) ไม่มีสูตรไหนฝัง `B<เลข>` ในซอร์ส ← ตัวจับ regression ของแท้
(2) ทุก key ที่อ้างมีจริง (3) key ไม่มีต้อง throw (4) key ซ้ำต้อง throw (5) `DASH_LBL` ตรงกับแผงและไม่ซ้ำ
ข้อ 1 ใช้ regex จับเฉพาะคอลัมน์ B — U/V/R/S เป็น helper คงที่ อ้างตรงๆ ได้
